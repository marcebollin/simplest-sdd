## How to inspect and use this session

1. Read `session.md` for the complete feedback grouped by image.
2. Open each numbered PNG in the same order as its section in `session.md`.
3. Match the numbered markers in each PNG with the numbered notes in that image's section.
4. Use `session.json` when exact coordinates, status, page metadata, or React context are useful.
5. Address every open note, preserve unrelated UI, and use resolved notes only as background context.
